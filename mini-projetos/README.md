# 🛠️ Mini-projetos

Um mini-projeto por fase do [Cyber Base](https://github.com/northtech-cyber/cyber-base). Cada um tem a sua pasta, com um `README.md` e os screenshots.

**Nome da pasta:** `fase-NN-tema` (ex.: `fase-01-redes`). O nome exato está no enunciado de cada fase.

Para começar um novo, copia o [`_modelo-mini-projeto.md`](_modelo-mini-projeto.md) para dentro da pasta como `README.md`.
