# 📒 Notas de estudo

Um ficheiro por fase: `fase-0.md`, `fase-1.md`, ...

Escreve com as tuas palavras. Explicar um conceito por escrito é a melhor forma de verificar se o percebeste.

Sugestão para cada nota:

- **Conceito:** o que é
- **Analogia:** como o explicarias a alguém fora da área
- **Na prática:** um comando, um filtro ou um exemplo
- **Dúvidas:** o que ainda não está claro (leva à sessão de mentoria)
