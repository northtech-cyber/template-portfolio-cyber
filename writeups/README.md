# 📝 Writeups

Relatórios completos de investigações. Um writeup deve ser compreensível por alguém que **não** fez o exercício.

Estrutura recomendada:

1. **Resumo executivo** — para um gestor, máx. 5 linhas
2. **Contexto** — de onde vieram os dados
3. **Cronologia** — tabela com hora e evento
4. **Análise técnica** — passos, filtros, prints
5. **IOCs** — desarmados (`exemplo[.]com`, `hxxp://`)
6. **Recomendações**
7. **Lições aprendidas**
